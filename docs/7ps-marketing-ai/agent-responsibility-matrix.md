Legenda:

- **R — Responsible:** executa o trabalho.
- **A — Accountable:** responde pela conclusão/qualidade daquela etapa.
- **C — Consulted:** contribui quando necessário.

## Regras adicionais

1. Nenhuma célula de "write Ads" entra em vigor antes da configuração formal de credenciais e política de alçada.
2. O Diretor é responsável pela interface humana, mas não precisa ser o autor de cada entrega.
3. O Estrategista é responsável pela coerência estratégica, não pela execução operacional de todas as peças.
4. O Analista deve manter separação entre dados e recomendação.
5. O Criativo deve usar ferramentas especializadas quando disponíveis e adequadas.
6. O Gestor recebe ativos aprovados de Copy/Criativo antes de uma futura publicação.
7. Quando uma atividade exigir várias etapas duráveis, deve ser representada no Kanban em vez de permanecer apenas em conversa.
